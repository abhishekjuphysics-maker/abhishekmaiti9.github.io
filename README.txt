- A personal domain is optional; check availability before purchasing.

Before publication:
- Confirm the correct MSCA grant amount. The supplied CV says “24K Euro,” which may be ambiguous; the site deliberately flags this rather than stating a guessed amount.
- Check whether “Principal Investigator” is the official wording you want to use for the MSCA fellowship role.
- This faculty-oriented research vision is a proposed framing based on the CV. Personalize it for each department and faculty application.
- The draft omits your phone number and referees' personal contact details for privacy.
- Only selected publications are listed; Google Scholar links to the full record.
- This is a static site, not yet deployed to a public URL.
